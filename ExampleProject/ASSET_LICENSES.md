# Showcase provenance

- Geometry/layout, visitor/controller/HUD, labels, room shader/material setup, animation,
  generator and prepared audio assets: original SpatialFabric contributions, MIT.
- Three source WAVs: original deterministic procedural warm percussion, stereo groove
  and glass/mechanical cue from NPLAudio/SpatialFabric v2.1.0; MIT, not third-party recordings.
  `SourceAssets/PROVENANCE.json` records exact source hashes and coordinate mapping.
- No Unreal packages, Epic FirstPerson/mannequin content, external meshes or sample libraries.
- Unity primitive meshes, Standard shader, runtime and built-in LegacyRuntime font are
  engine-supplied references, governed by Unity's terms, not vendored/relicensed as MIT.
- `RoomText.shader` is original code using Unity's supplied dynamic font atlas at runtime.

This scene is a software showcase, not physical device/fidelity/latency certification.
